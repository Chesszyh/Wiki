    本文档描述了 Codex 如何维护和操作构成模型上下文窗口的对话历史。它涵盖了 ContextManager 数据结构、项的记录与归一化、Token 估算以及历史生命周期管理。

    有关在接近上下文限制时总结和压缩对话历史的详细信息，请参见 历史压缩系统。有关将历史持久化到磁盘并在会话恢复期间重放的信息，请参见 Rollout 持久化与重放。

    概述¶

    对话历史管理器负责：

    • 存储 ResponseItem 条目（用户消息、助手消息、工具调用、工具输出、推理项） codex-rs/core/src/context_manager/history.rs30-33
    • 对历史进行归一化以维持不变性，例如确保每个工具调用都有对应的输出 codex-rs/core/src/context_manager/normalize.rs14-16
    • 跟踪来自 API 响应的 Token 使用情况，并对本地添加的项进行 Token 估算 codex-rs/core/src/context_manager/history.rs126-133
    • 通过过滤和转换项，为 Prompt 构建准备历史记录 codex-rs/core/src/context_manager/history.rs112-117
    • 支持历史修改操作，如移除、替换和压缩 codex-rs/core/src/context_manager/history.rs151-174

    主要入口点是 ContextManager 结构体，它由 SessionState 拥有并由 Session 方法操作 codex-rs/core/src/state/session.rs20-22
