## 目的与范围

本文解释 OpenCV 的跨平台构建配置系统，涵盖平台检测、编译器配置和第三方库集成。该构建系统使用 CMake 来检测目标平台、配置编译器并定位依赖。关于模块级配置，请参见第 2.2 页。

## 平台检测与配置

OpenCV 使用 CMake 检测目标平台并自动应用相应配置。流程从主 `CMakeLists.txt` 文件开始，在其中收集系统信息并加载平台特定文件。

### 构建系统初始化流程

```mermaid
flowchart TD
    A["include(cmake/OpenCVMinDepVersions.cmake)"]
    B["project(OpenCV CXX C)"]
    C["CMAKE_SYSTEM_NAME set by CMake"]
    D["include(cmake/platforms/OpenCV-${CMAKE_SYSTEM_NAME}.cmake)"]
    E["include(cmake/OpenCVDetectCXXCompiler.cmake)"]

    G["ocv_cmake_hook(POST_DETECT_COMPILER)"]
    H["include(cmake/OpenCVCompilerOptions.cmake)"]
    I["CMAKE_CXX_FLAGS configuration"]
    J["CMAKE_INSTALL_PREFIX setup"]

    A --> B
    B --> C
    C --> D
    D --> E
    E --> F
    F --> G

    H --> I
    I --> J
```

### 交叉编译时的调整

当 `CMAKE_CROSSCOMPILING` 为 true 时：

| 调整项 | 配置 |
| --- | --- |
| 安装路径 | `CMAKE_INSTALL_PREFIX = ${CMAKE_BINARY_DIR}/install` |
| pkg-config | 除非设置 `PKG_CONFIG_LIBDIR` 或 `PKG_CONFIG_SYSROOT_DIR`，否则禁用 |
| 系统库 | 库检测受限，主要使用内置 3rdparty |
| 模块选择 | 部分模块会根据目标平台被禁用 |

## 构建定制机制

OpenCV 通过 CMake hook 与环境变量支持构建定制。

### CMake Hook 系统

该 hook 系统允许在特定构建阶段注入自定义 CMake 脚本：

```mermaid
flowchart TD
    A["Environment: OPENCV_CMAKE_HOOKS_DIR"]
    B["ocv_check_environment_variables(OPENCV_CMAKE_HOOKS_DIR)"]
    C["ocv_cmake_hook_register_dir(__dir)"]
    D["file(GLOB hook_files ${__dir}/*.cmake)"]
    E["ocv_cmake_hook_append(hook_name ${__dir}/${f})"]
    F["Hook execution points:"]
    G["ocv_cmake_hook(CMAKE_INIT)"]
    H["ocv_cmake_hook(PRE_CMAKE_BOOTSTRAP)"]
    I["ocv_cmake_hook(POST_CMAKE_BOOTSTRAP)"]
    J["ocv_cmake_hook(POST_DETECT_COMPILER)"]
    K["ocv_cmake_hook(POST_COMPILER_OPTIONS)"]

    A --> B
    B --> C
    C --> D
    D --> E
    E --> F
    F --> G
    G --> H
    H --> I
    I --> J
    J --> K
```
Hook 文件按 hook 点命名（例如 `POST_DETECT_COMPILER.cmake`），并会自动注册。

来源： [cmake/OpenCVUtils.cmake69-86](https://github.com/opencv/opencv/blob/91c78f50/cmake/OpenCVUtils.cmake#L69-L86) [CMakeLists.txt98-108](https://github.com/opencv/opencv/blob/91c78f50/CMakeLists.txt#L98-L108)

### 环境变量集成

`ocv_check_environment_variables()` 会从环境变量导入路径：

```mermaid

    B["${var} empty ANDENV${var} defined?"]
    C["__value = ENV${var}"]
    D["file(TO_CMAKE_PATH ${__value} __value)"]
    E["set(${var} ${__value})"]
    F["message(STATUS 'Update variable ${var}from environment: ${${var}}')"]
    G["Keep CMake variable value"]

    A --> B
    B --> C
    C --> D
    D --> E
    E --> F
    B --> G
```

## 结论

OpenCV 的跨平台构建配置系统是一套复杂而完善的机制，使该库能够在多样化的硬件与软件环境中被有效编译与使用。系统能够智能检测平台特征和可用依赖，从而为每个目标环境提供优化后的构建结果。

对于需要为特定平台定制 OpenCV 构建，或将 OpenCV 集成到跨平台项目中的开发者而言，理解这套配置系统至关重要。
