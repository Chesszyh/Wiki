## 先决条件 (Prerequisites)

| 要求 | 详情 |
| --- | --- |
| **Node.js** | 版本 22 或更高 (`node --version` 可查看) |
| **包管理器** | npm 或 pnpm；**推荐使用 pnpm** |
| **操作系统** | macOS, Linux, 或通过 WSL2 使用 Windows (在 Windows 上强烈推荐使用 WSL2) |
| **内存 (RAM)** | 个人使用最少 512MB-1GB；推荐 2GB 以留出日志/媒体空间 |
| **磁盘空间** | 网关安装约需 500MB |

在进程启动时，通过 `assertSupportedRuntime` 强制执行最低运行时要求，然后才会运行任何命令。**不推荐**将 Bun 用于网关。

## 安装 (Installation)

支持三种安装路径：

| 方法 | 命令 | 使用场景 |
| --- | --- | --- |
| **安装脚本 (推荐)** | `curl -fsSL https://openclaw.ai/install.sh | bash` | 大多数用户；自动处理 Node 检测、安装、PATH 设置和入门向导 |
| **npm/pnpm 全局安装** | `npm install -g openclaw@latest` | PATH 上已存在 Node >= 22 的干净安装 |
| **从源码安装 (git)** | `git clone` + `pnpm install && pnpm build` | 贡献者和开发；允许本地修改 |

### 安装脚本 (推荐)

安装脚本会自动检测 Node，如果缺失则进行安装，通过 npm 全局安装 OpenClaw，并启动入门向导。

**macOS/Linux/WSL2:**

```
curl -fsSL https://openclaw.ai/install.sh | bash
```
**Windows (PowerShell):**

```
iwr -useb https://openclaw.ai/install.ps1 | iex
```
**跳过入门向导 (仅安装二进制文件):**

```
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --no-onboard
```
**从 git 检出安装 (可修改的安装):**

```
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --install-method git
```
`--install-method git` 标志会克隆存储库并从源码安装，允许您在本地修改代码。这对于开发或当 AI 编码助手需要读取完整源码树时非常有用。

来源：[docs/help/faq.md318-332](https://github.com/openclaw/openclaw/blob/8873e13f/docs/help/faq.md#L318-L332) [docs/install/installer.md14-67](https://github.com/openclaw/openclaw/blob/8873e13f/docs/install/installer.md#L14-L67)

### npm/pnpm

如果您已经安装了 Node 22+:

```
npm install -g openclaw@latest
# 或
pnpm add -g openclaw@latest
```
安装后，运行入门向导：

```
openclaw onboard --install-daemon
```
来源：[docs/install/index.md72-85](https://github.com/openclaw/openclaw/blob/8873e13f/docs/install/index.md#L72-L85)

### 从源码安装 (Git)

适用于贡献者或开发工作流：

```
git clone https://github.com/openclaw/openclaw.git
cd openclaw
pnpm install
pnpm build
pnpm ui:build   # 构建 Control UI 资产；首次运行时会自动安装 UI 依赖
```
对于源码安装：

-   `pnpm openclaw ...` 会通过 tsx 直接运行 TypeScript 代码。
-   修改本地代码会立即生效（如果使用 `openclaw gateway run`）。
