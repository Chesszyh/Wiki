## 身份验证模式 (Authentication Modes)

启动时，网关从配置和环境中解析出一个单一的 `ResolvedGatewayAuth` 对象。随后的每一次身份验证检查都会读取该对象。

**定义于：** `src/gateway/auth.ts` — `ResolvedGatewayAuth` 类型 [\`src/gateway/auth.ts30-37](https://github.com/openclaw/openclaw/blob/8873e13f/`src/gateway/auth.ts#L30-L37)

| 模式 (`ResolvedGatewayAuthMode`) | 凭据 | 典型用途 |
| --- | --- | --- |
| `"token"` | 共享密钥字符串；`OPENCLAW_GATEWAY_TOKEN` 环境变量或 `gateway.auth.token` | 默认 |
| `"password"` | 网关密码；`gateway.auth.password` | 令牌的替代方案 |
| `"trusted-proxy"` | 由反向代理通过 HTTP 标头注入的身份 | SSO / Tailscale Serve |
| `"none"` | 无需凭据 | 仅限本地回环、开发环境 |

Tailscale 对等方身份验证是一个独立的覆盖层，由 `ResolvedGatewayAuth` 上的 `allowTailscale: boolean` 控制。它仅在 WS 控制 UI 界面可用 (`authorizeWsControlUiGatewayConnect`)，HTTP 界面不可用。

`GatewayAuthResult.method` 字段报告身份验证实际是如何解析的：

```
"none" | "token" | "password" | "tailscale" | "device-token" | "trusted-proxy"
```
