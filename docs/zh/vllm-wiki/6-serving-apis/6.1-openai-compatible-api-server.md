本文档介绍通过 OpenAI 兼容 REST API 暴露 vLLM 推理能力的基于 FastAPI 的 HTTP 服务器。它涵盖服务器入口点、启动序列、路由注册、中间件栈、引擎客户端生命周期以及多进程部署模式。

## CLI 入口点 (CLI Entry Points)

vLLM CLI 通过 `CLISubcommand` 基类分发子命令。`serve` 子命令是 API 服务器的主要入口点。

`ServeSubcommand.cmd()` 中的分发逻辑会检查 `args.api_server_count`：

| 条件 | 模式 | 函数 |
| --- | --- | --- |
| `api_server_count == 1` | 单进程 | `run_server(args)` |
| `api_server_count > 1` | 多进程（数据并行） | `run_multi_api_server(args)` |
| `api_server_count < 1` | 无头（仅引擎） | `run_headless(args)` |

## 服务器启动序列 (Server Startup Sequence)

`run_server_worker()` `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/openai/api_server.py#L474-L530" min=474 max=530 file-path="vllm/entrypoints/openai/api_server.py">Hii</FileRef>` 执行的关键启动步骤：

1.  **`setup_server(args)`** – 验证参数，绑定套接字（TCP 或 Unix 域套接字），设置 `ulimit`，安装 `SIGTERM` 处理器 `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/openai/api_server.py#L419-L461" min=419 max=461 file-path="vllm/entrypoints/openai/api_server.py">Hii</FileRef>`。
2.  **`build_async_engine_client(args)`** – 异步上下文管理器，创建 `AsyncLLM` 引擎，并在服务器生命周期内返回 `EngineClient` `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/openai/api_server.py#L78-L106" min=78 max=106 file-path="vllm/entrypoints/openai/api_server.py">Hii</FileRef>`。
3.  **`engine_client.get_supported_tasks()`** – 查询引擎以发现已加载模型支持哪些任务类型。
4.  **`build_app(args, supported_tasks)`** – 构建 `FastAPI` 应用，注册所有路由，并应用中间件 `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/openai/api_server.py#L157-L238" min=157 max=238 file-path="vllm/entrypoints/openai/api_server.py">Hii</FileRef>`。
5.  **`init_app_state(engine_client, app.state, args, supported_tasks)`** – 将引擎客户端、服务模型、分词服务以及按任务划分的服务处理器填充到 `app.state` 中 `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/openai/api_server.py#L291-L379" min=291 max=379 file-path="vllm/entrypoints/openai/api_server.py">Hii</FileRef>`。
6.  **`serve_http(app, sock=sock, ...)`** – 启动 uvicorn 服务器循环 `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/launcher.py#L29-L29" min=29 file-path="vllm/entrypoints/launcher.py">Hii</FileRef>`。

关键行为：

-   **Forkserver 设置**：如果 `VLLM_WORKER_MULTIPROC_METHOD=forkserver`，则会预加载 `vllm.v1.engine.async_llm`，以优化进程创建 `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/openai/api_server.py#L84-L91" min=84 max=91 file-path="vllm/entrypoints/openai/api_server.py">Hii</FileRef>`。

-   **优雅关闭**：`finally` 代码块确保调用 `async_llm.shutdown()`，从而清理 GPU 资源和 IPC 套接字 `<FileRef file-url="https://github.com/vllm-project/vllm/blob/7cc302dd/vllm/entrypoints/openai/api_server.py#L152-L154" min=152 max=154 file-path="vllm/entrypoints/openai/api_server.py">Hii</FileRef>`。
