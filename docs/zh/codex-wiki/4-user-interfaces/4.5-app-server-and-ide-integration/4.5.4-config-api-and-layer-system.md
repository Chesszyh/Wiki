## 目的与范围

本页记录 app-server 暴露的配置 API，以及支撑 Codex 运行时行为的分层配置系统。Config API 提供用于读取与写入配置值的 JSON-RPC 端点；分层系统则决定来自多种来源（MDM、系统文件、用户文件、项目文件、CLI 参数）的设置如何按优先级规则合并。

关于认证配置信息，参见 [Authentication Modes and Account Management](/openai/codex/4.5.5-authentication-modes-and-account-management)。关于功能开关管理，参见 [Feature Flags](/openai/codex/2.3-feature-flags)。关于核心配置类型与 schema，参见 [Configuration System](/openai/codex/2.2-configuration-system)。
