Python SDK（`codex-app-server-sdk`）提供了一个高级接口，用于将 Codex 代理嵌入 Python 应用。它充当 Codex CLI 与 App Server JSON-RPC 协议之上的封装层，便于线程管理、轮次执行与结构化数据交换。

## 概览

该 SDK 允许开发者通过同步或异步客户端与 Codex 交互。它管理底层 `codex` 进程的生命周期，处理 JSON-RPC 通信，并提供 Pydantic 模型以实现与协议线缆格式的类型安全交互。

### 关键组件

-   **Codex Client**: 用于启动或恢复对话的主要入口。
-   **Thread**: 表示持久化会话。
-   **Turn**: 表示线程中的一次交互（输入与响应）。
-   **Pydantic Models**: 映射 Rust 定义的协议，用于校验与 IDE 自动补全。

---

## 架构与数据流

Python SDK 通过 `app-server` 协议与 Codex 核心通信。它通常在后台拉起一个 Codex 进程，并通过标准 I/O（stdin/stdout）交换 JSON-RPC 消息。

### 进程生命周期与通信

SDK 抽象了进程管理与协议协商的复杂性。

| 组件 | 职责 |
| --- | --- |
| `Codex` Class | 管理进程拉起与全局配置。 |
| `Thread` Class | 跟踪 `thread_id` 并管理基于轮次的状态。 |
| `CodexExec` | 处理 `spawn` 与环境变量的底层工具。 |

## 客户端与线程管理

SDK 支持两种主要执行模式：**Direct Exec**（为短生命周期任务拉起 CLI）与 **App Server**（连接持久化 JSON-RPC 服务器）。

### 线程生命周期

`Thread` 可通过启动全新会话或通过 `thread_id` 恢复现有会话来初始化。

-   **启动**: `codex.start_thread()` 在 `~/.codex/sessions` 中生成新会话。
-   **恢复**: `codex.resume_thread(thread_id)` 从 rollout 文件重新加载历史 [sdk/typescript/src/thread.ts160-161](https://github.com/openai/codex/blob/d807d44a/sdk/typescript/src/thread.ts#L160-L161)
-   **执行**: `run()` 方法是阻塞调用并返回已完成的 `Turn`，而 `run_streamed()` 返回异步生成器 [sdk/typescript/src/thread.ts66-138](https://github.com/openai/codex/blob/d807d44a/sdk/typescript/src/thread.ts#L66-L138)

### 配置与环境

SDK 允许通过环境变量与经由 `CodexExec` 封装器传递的 CLI 标志覆盖核心行为。

| 参数 | 代码实体 / 标志 | 说明 |
| --- | --- | --- |
| API Key | `CODEX_API_KEY` | 用于 OpenAI/远程模型的认证。 |
| Base URL | `--config openai_base_url` | 将 API 调用重定向到自定义端点。 |
| Sandbox | `--sandbox` | 设置策略（例如 `workspace-write`）。 |
| Originator | `CODEX_INTERNAL_ORIGINATOR_OVERRIDE` | 标识客户端（例如 `codex_sdk_py`）。 |

## 协议与线缆模型

SDK 依赖与 Rust `app-server-protocol` crate 保持同步的 Pydantic 模型。这些模型定义了在线缆上传输的每一类消息结构。

### JSON-RPC 消息结构

所有通信均遵循 JSON-RPC 2.0 规范，并封装在类似枚举的 `JSONRPCMessage` 结构中。

## 高级特性

### 结构化输出

SDK 支持强制代理返回匹配特定 schema 的 JSON。这通过向 `TurnOptions` 的 `output_schema` 参数传递 `JSON Schema` 来实现。

-   **实现**: SDK 将 schema 写入临时文件，并向 Codex 进程传递 `--output-schema <path>` [sdk/typescript/src/thread.ts74-87](https://github.com/openai/codex/blob/d807d44a/sdk/typescript/src/thread.ts#L74-L87)
-   **校验**: 响应作为 `AgentMessageItem` 的一部分返回，其中 `text` 字段包含 JSON 字符串 [sdk/typescript/src/items.ts73-79](https://github.com/openai/codex/blob/d807d44a/sdk/typescript/src/items.ts#L73-L79)

### 工具与 MCP 集成

当 Codex 调用工具（shell、补丁或 MCP）时，SDK 会将其呈现为特定的 `ThreadItem` 类型：

-   **CommandExecutionItem**: 捕获命令、状态与 `aggregated_output` [sdk/typescript/src/items.ts9-20](https://github.com/openai/codex/blob/d807d44a/sdk/typescript/src/items.ts#L9-L20)
-   **McpToolCallItem**: 捕获服务器名称、工具名称与参数 [sdk/typescript/src/items.ts51-71](https://github.com/openai/codex/blob/d807d44a/sdk/typescript/src/items.ts#L51-L71)
