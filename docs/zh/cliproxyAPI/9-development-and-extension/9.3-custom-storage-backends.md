## 用途与范围

CLIProxyAPI 提供了一个灵活的存储抽象层，用于持久化身份验证凭据和配置。虽然系统附带了针对文件系统、PostgreSQL、Git 和 S3 兼容的对象存储的内置支持，但开发者可以实现自定义存储后端以集成专有的数据库、机密管理器或云服务。

本页面定义了存储接口，并演示了如何创建和注册自定义后端。有关内置存储选项的比较，请参阅第 5.2 页。有关云原生部署设置，请参阅第 10.2 页。

## `Store` 接口

所有存储后端必须实现定义在 `sdk/cliproxy/auth/conductor.go` 中的 `Store` 接口。

### 接口定义

```go
type Store interface {
    // 基础操作
    Load(ctx context.Context) ([]*Auth, error)
    Save(ctx context.Context, auth *Auth) error
    Delete(ctx context.Context, authID string) error
    
    // 资源持久化 (用于 config.yaml)
    PersistConfig(ctx context.Context, path string, data []byte) error
    
    // 初始引导
    Bootstrap(ctx context.Context, exampleConfigPath string) error
}
```

### 方法说明

| 方法 | 职责 |
| --- | --- |
| `Load()` | 从后端检索所有认证条目。由认证管理器在启动时调用。 |
| `Save()` | 持久化单个认证条目。在 OAuth 刷新或手动更新后调用。 |
| `Delete()` | 永久移除一个认证条目。 |
| `PersistConfig()` | 将 `config.yaml` 内容保存到后端。用于管理 API 更新。 |
| `Bootstrap()` | 初始化后端架构并确保存在有效的起始配置。 |

## 实现自定义存储

### 1. 定义存储结构

```go
type RedisTokenStore struct {
    client *redis.Client
    prefix string
}

func NewRedisTokenStore(addr, password string) *RedisTokenStore {
    return &RedisTokenStore{
        client: redis.NewClient(&redis.Options{Addr: addr, Password: password}),
        prefix: "cliproxy:auth:",
    }
}
```

### 2. 实现 Save 方法

`Save` 应当将 `Auth` 对象序列化为 JSON 并将其存储。

```go
func (s *RedisTokenStore) Save(ctx context.Context, auth *auth.Auth) error {
    data, _ := json.Marshal(auth)
    key := s.prefix + auth.ID
    return s.client.Set(ctx, key, data, 0).Err()
}
```

### 3. 实现 Load 方法

`Load` 应当扫描所有键并反序列化认证条目。

```go
func (s *RedisTokenStore) Load(ctx context.Context) ([]*auth.Auth, error) {
    keys, _ := s.client.Keys(ctx, s.prefix + "*").Result()
    var results []*auth.Auth
    for _, k := range keys {
        data, _ := s.client.Get(ctx, k).Bytes()
        var a auth.Auth
        json.Unmarshal(data, &a)
        results = append(results, &a)
    }
    return results, nil
}
```

## 注册自定义存储

自定义存储必须在 `main()` 函数中或在通过 SDK 构建 `Service` 时注册。

### 通过 SDK 注册

```go
myStore := NewRedisTokenStore("localhost:6379", "")

svc := cliproxy.NewBuilder().
    WithTokenStore(myStore).
    Build()
```

### 全局注册

如果手动初始化组件，请向认证管理器注册：

```go
manager := auth.NewManager(cfg)
manager.SetStore(myStore)
```
