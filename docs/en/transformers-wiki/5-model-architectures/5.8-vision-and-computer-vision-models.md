The Transformers library provides a comprehensive suite of models for computer vision tasks, ranging from general-purpose image encoders to specialized architectures for object detection and segmentation. These models leverage the same `PreTrainedModel` base class as their NLP counterparts, enabling a unified API for loading, saving, and inference across modalities.

## Contrastive Vision-Language Models (CLIP/SigLIP)

Contrastive models like CLIP and SigLIP are trained to align images and text in a shared embedding space. They consist of a vision encoder and a text encoder, where the goal is to maximize the similarity between matching pairs.

### Implementation Details

-   **CLIP**: Uses a causal mask for its text encoder `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/clip/modeling_clip.py#L25-L25" min=25 file-path="src/transformers/models/clip/modeling_clip.py">Hii</FileRef>` and a vision encoder that includes a learned `class_embedding` prepended to patch embeddings `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/clip/modeling_clip.py#L146-L146" min=146 file-path="src/transformers/models/clip/modeling_clip.py">Hii</FileRef>`.
-   **SigLIP**: Replaces the standard softmax cross-entropy loss with a pairwise sigmoid loss, which is more memory-efficient and performs better at scale. Unlike CLIP, SigLIP's vision encoder often omits the `class_embedding` in favor of global average pooling or a dedicated attention pooling head `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/siglip/modeling_siglip.py#L133-L152" min=133 max=152 file-path="src/transformers/models/siglip/modeling_siglip.py">Hii</FileRef>`.
-   **Loss Functions**: CLIP utilizes `contrastive_loss` applied to both image-to-text and text-to-image similarities `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/clip/modeling_clip.py#L47-L54" min=47 max=54 file-path="src/transformers/models/clip/modeling_clip.py">Hii</FileRef>`.

## Image Encoders and Backbones (ViT, DINOv2)

Pure vision models serve as the foundation for downstream tasks. The library supports standard Vision Transformers (ViT) and self-supervised variants like DINOv2.

### Key Components

-   **Patch Embeddings**: Images are split into fixed-size patches and projected into a linear embedding space using a 2D convolution `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/siglip/modeling_siglip.py#L124-L130" min=124 max=130 file-path="src/transformers/models/siglip/modeling_siglip.py">Hii</FileRef>`.
-   **Position Encoders**: Since Transformers are permutation-invariant, position embeddings are added. Models like DINOv2 support `interpolate_pos_encoding` to handle dynamic input resolutions `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/siglip/modeling_siglip.py#L137-L160" min=137 max=160 file-path="src/transformers/models/siglip/modeling_siglip.py">Hii</FileRef>`.
-   **Backbone Utilities**: The `AutoBackbone` class and `load_backbone` utility allow vision models to be used as feature extractors within larger architectures (e.g., in DETR) `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/backbone_utils.py#L32-L32" min=32 file-path="src/transformers/backbone_utils.py">Hii</FileRef>`.

## Object Detection (DETR & Deformable-DETR)

Object detection models in Transformers typically follow the DETR (DEtection TRansformer) paradigm, which treats detection as a set prediction problem using a Transformer encoder-decoder.

### Architecture Features

-   **Object Queries**: A fixed set of learned embeddings that interact with image features in the decoder to predict bounding boxes and classes `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/deformable_detr/modeling_deformable_detr.py#L84-L98" min=84 max=98 file-path="src/transformers/models/deformable_detr/modeling_deformable_detr.py">Hii</FileRef>`.
-   **Deformable Attention**: Used in `DeformableDetr` to attend only to a small set of key sampling points around a reference, significantly speeding up convergence and handling multi-scale features `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/deformable_detr/modeling_deformable_detr.py#L58-L74" min=58 max=74 file-path="src/transformers/models/deformable_detr/modeling_deformable_detr.py">Hii</FileRef>`.
-   **Two-Stage Detection**: Some variants like Deformable-DETR use a first stage to generate region proposals that initialize the reference points for the second stage `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/deformable_detr/modeling_deformable_detr.py#L92-L98" min=92 max=98 file-path="src/transformers/models/deformable_detr/modeling_deformable_detr.py">Hii</FileRef>`.

## Segmentation (SAM, Mask2Former)

The library provides models for semantic, instance, and panoptic segmentation, including the Segment Anything Model (SAM).

### Segment Anything Model (SAM)

SAM is designed for promptable segmentation. It consists of three modules:

1.  **VisionEncoder**: A heavy ViT-based encoder that produces image embeddings `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/sam/modeling_sam.py#L47-L57" min=47 max=57 file-path="src/transformers/models/sam/modeling_sam.py">Hii</FileRef>`.
2.  **PromptEncoder**: Encodes sparse prompts (points, boxes) and dense prompts (masks) into tokens `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/sam/modeling_sam.py#L34-L34" min=34 file-path="src/transformers/models/sam/modeling_sam.py">Hii</FileRef>`.
3.  **MaskDecoder**: A Transformer decoder that maps the image embedding and prompt tokens to mask predictions and IoU scores `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/sam/modeling_sam.py#L65-L95" min=65 max=95 file-path="src/transformers/models/sam/modeling_sam.py">Hii</FileRef>`.

### Mask2Former and MaskFormer

These models use a "mask classification" approach.

-   **Pixel Decoder**: Computes per-pixel embeddings and multi-scale features `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/mask2former/modeling_mask2former.py#L46-L70" min=46 max=70 file-path="src/transformers/models/mask2former/modeling_mask2former.py">Hii</FileRef>`.
-   **Transformer Decoder**: Predicts a set of binary masks and their corresponding category labels `<FileRef file-url="https://github.com/huggingface/transformers/blob/9a9997fd/src/transformers/models/mask2former/modeling_mask2former.py#L143-L160" min=143 max=160 file-path="src/transformers/models/mask2former/modeling_mask2former.py">Hii</FileRef>`.
